# 晚安绘本馆

面向儿童的中文睡前绘本视频系列。生产以单集结构化剧本为源文件，以第001集第二版为已验收的声音、画面和剪辑基准。

## 制作规范

- [生产手册](docs/production/README.md)：制作顺序、状态与交付边界。
- [声音规范](docs/production/VOICE_PROFILE.md)：已验收音色、语速、后期与停顿参数。
- [视频规范](docs/production/VIDEO_SPEC.md)：画面风格、分镜、运镜、转场、混音与导出。
- [单集流程](docs/production/EPISODE_WORKFLOW.md)：从指定剧本到验收成片的逐集流程。
- [单集记录模板](docs/production/templates/EPISODE_RECORD.md)：留存版本、素材、实际参数与验收证据。

## 基准与边界

第001集《小兔子皮皮的晚安星光》第二版是唯一已验收成片。第002–100集目前有剧本、九镜分镜和绘图提示词；它们的专属配音、图片与成片尚未制作。不要把计划或占位文件标为已完成。

改稿时以结构化JSON为唯一剧本源；Markdown是阅读视图。具体文件包和程序尚需导入本仓库后，才能链接到对应的剧本、参数和制作脚本。
