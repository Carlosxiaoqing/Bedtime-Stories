# 单集制作流程

一次只处理明确指定的集数。下例中的 `002` 可替换为目标集数；命令以解包后的原制作包为准。

## 1. 准备

从结构化JSON读取故事、逐镜旁白、停顿、画面、机位和绘图提示词，并读取共用画风、角色与声音参数。Markdown是阅读视图，不作为独立改稿源。核对集数、版本和已有素材状态。

## 2. 生成配音

确认台词后按声音规范逐句TTS。保存每句源MP3、文本、音色、rate、pitch及缓存摘要。试听全段，检查空音频、错读、断句与句尾；以真实解码时长生成纯配音轨和句级字幕基准。

## 3. 准备插画

按九镜逐张生成竖版原图，命名 `shot_01.png` 至 `shot_09.png`。记录每张提示词、参考图用途、真实尺寸与来源。检查角色锚点、动作、地点和连续性，再确认可用；图片不足时停在素材准备阶段，不用占位图进入成片。

## 4. 时间轴与渲染

结合真实语音、JSON停顿和语义切点编排时间轴。渲染时遵循25fps与0.96秒叠化预留公式，生成独立字幕和实际时间轴文件。使用本地慢推拉和必要的局部微动；微动位置必须按新图重新标定。

## 5. 检查和交付

运行完整解码和规格检查，试听中段、结尾并完整看听一次。缺陷按素材、语音、时间轴、字幕、渲染或主观听感分类返工；局部变化只重做受影响步骤。交付成片、纯配音、混音、SRT、时间轴、项目参数、素材清单和检查报告。

## 状态定义

| 阶段 | 完成证据 |
| --- | --- |
| 剧本完成 | JSON版本已确认，Markdown已同步导出 |
| 配音完成 | 所有句子有可解码源音频，整段已试听 |
| 插画完成 | 计划镜头图齐备、逐张对应剧情并通过检查 |
| 渲染完成 | 成片、字幕和时间轴文件已生成 |
| 技术通过 | 解码、尺寸、帧率、音画时长、字幕和削波检查通过 |
| 人工通过 | 完整听看并记录声线、节奏、配乐和画面意见 |

任何未执行阶段都明确写作未完成或受阻，不以计划、脚本或占位素材宣称成片完成。
