面向儿童的中文睡前绘本视频系列。生产以单集结构化剧本为源文件，以第001集第二版为已验收的声音、画面和剪辑基准。

## 基准与边界

第001集《小兔子皮皮的晚安星光》第二版是唯一已验收成片。第002–100集目前有剧本、九镜分镜和绘图提示词；它们的专属配音、图片与成片尚未制作。不要把计划或占位文件标为已完成。

改稿时以结构化JSON为唯一剧本源；Markdown是阅读视图。当前已导入01制作手册、02剧本和03素材参数。04生产程序、首集媒体和05验收文件尚未导入，因此目前可以查阅与规划制作，尚不能按包内命令直接运行完整生产流程。
