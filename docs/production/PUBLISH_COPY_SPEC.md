# 三平台标题与正文交付规范

版本：1.2｜2026-11-15（北京时间）。每集交抖音、小红书、微信视频号三份发布文案；标题按用户最新要求与封面统一，正文分别写并各自含标签。

## 标题的唯一取值

三平台发布标题统一取本集`cover-plan.json.title`，与封面逐字完全相同，使用6–10个汉字“皮皮＋本集真实的一件事”。不得再用旧四字主题替代封面标题，也不另加平台副标题、集号或系列前缀。详见[封面规范](COVER_SPEC.md)。

口播故事原名与v5 p000不因发布标题改变；如需说明原名，放在发布正文。标题要有v5正文依据，不编造动作，不把配角做的事写成皮皮做的。

## 文案格式与正文

每集交付`发布文案.md`，保留以下三个独立章节；标题行使用`**标题：**`格式，供工具校验：

```markdown
## 抖音

**标题：** 与cover-plan.json.title逐字相同

**正文：** 根据当集真实事件写正文。

#睡前故事 #儿童故事 #亲子陪伴

## 小红书

**标题：** 与cover-plan.json.title逐字相同

**正文：** 根据亲子阅读场景另写正文。

#睡前故事 #儿童绘本 #亲子共读

## 微信视频号

**标题：** 与cover-plan.json.title逐字相同

**正文：** 根据家庭分享场景另写正文。

#睡前故事 #亲子陪伴 #儿童故事
```

| 平台 | 正文编辑目标（不是平台字数上限） |
| --- | --- |
| 抖音 | 1–3句，简洁说明具体故事和适用场景 |
| 小红书 | 2–4个短段，可稍详细地描述情境、亲子阅读场景及特色 |
| 微信视频号 | 自然温暖，方便家庭分享，可在正文说明故事原名 |

每份正文末尾放3–5个相关#标签，整段可复制。根据内容选睡前故事/儿童绘本、亲子共读和具体物件/主题，不堆热点，不以标签承诺平台流量。

## 抖音正文：具体视角与真实感受

依据用户提供的抖音作品诊断建议，后续抖音正文在1–3句内优先包含：本集一个真实情节细节、创作者对该细节的具体感受或观察、一个自然且与故事相关的开放问题。可写“我喜欢这个结尾，因为……”或“故事里让我记住的是……”，避免只有通用剧情简介。

感受必须能由本集真实内容支撑，不编造创作者经历、观众反馈或制作过程；提问用于自然交流，不承诺流量、不诱导互动。此规则只优化抖音发布正文，不改口播、字幕、标题，也不自动套用于小红书和微信视频号。

## 与视频一致

描述当集真实内容，不添加未呈现角色或新情节。拼音字幕可表述为“每个汉字上方配有拼音”，不承诺识字效果；避免“秒睡”“治愈失眠”等效果承诺。保留现有开场及尾声，不新增视频内口号、关注引导、教学跟读或结尾预告钩子。

可先起草正文并标待成片核对；交付前核对标题、正文、封面和字幕真实存在且一致。三份文案完成不代表已发布，平台链接和时间另外记录，发布需有授权。

## 检查清单

- 三平台都有与封面完全相同的6–10字“皮皮＋一件事”标题，各有独立正文。
- 每份正文末尾有相关标签，内容与本集v5剧情和实际成片一致。
- 运行`python3 local/cover_assets.py --output-dir episodes/epNNN/vNNN --validate-only --check-copy`；自动检查只核对配置和标题，内容准确性仍需审读。
- 发布前查看平台实际预览、字数及话题规则，不假设固定平台限制。
