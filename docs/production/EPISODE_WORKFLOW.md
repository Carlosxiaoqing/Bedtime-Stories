# 单集制作流程

一次只处理用户指定集数或批次。当前04生产程序尚未导入，本页描述执行顺序，不提供不存在的可运行命令；补齐材料见[交接](../../HANDOFF.md)。

## 1. 锁定内容和状态

读取主控、台账、目标集JSON/阅读视图与共用参数。核对集号、稿件版本、是否已有占用任务及已有媒体。建立本集RECORD并同步主控/台账；改稿只改JSON再同步阅读视图。故事不变时不重新选题。

建议工程目录：`04_生产工程/工作工程/epNNN/vNNN/`，保留`project.json`、`RECORD.md`、`images/`、`audio/`、`cover/`、`subtitles/`、`导出/`、`检查/`。这些是后续创建约定，当前尚无这些单集工程。

## 2. 配音与实测时间

按[声音规范](VOICE_PROFILE.md)使用晓晓`-25%/-2Hz/+0%`逐句合成，保存源MP3、文本、实际参数和缓存摘要。先试听代表片段，再合成全篇；检查错读、空音频与句尾，以真实解码音频和JSON停顿编排时间轴。

## 3. 九张插画与独立封面

按九镜提示词逐张生成`shot_01.png`至`shot_09.png`；记录原始尺寸、来源、提示词及角色参考。按[封面规范](COVER_SPEC.md)另交1张封面：选本集内容图，套用固定模板，替换4–6字优先的短标题。可以复用本集原图作底图，不能拿无关图或布局占位冒充封面成品。

## 4. 拼音字幕与预检

按[字幕规范](SUBTITLE_SPEC.md)从原稿生成逐字音节映射，人工校对多音字、轻声、变调与儿化，再按真实口播切成短语。保存字级JSON、ASS、兼容SRT；检查每字上方的拼音和汉字居中对齐。

先做约20秒代表片段，覆盖长音节、长短句、两组排版和深浅背景；用手机尺度检查64px汉字/30px拼音是否清楚，不能只检查电脑放大图。发现遮挡先改构图/字幕块位置或拆句，不缩成小字。首个真实模板样片记录为待审，不写成已获用户验收。

## 5. 合成和导出

以真实语音、停顿与语义决定镜头边界，按25fps、0.96秒叠化及预留公式渲染；局部微动按新图标定。先合成无字幕母版，再叠拼音字幕为发布版，保留完整原音轨。检查末句后字幕消失、约8秒尾声和末4秒渐暗。

导出`epNNN.mp4`（有拼音发布版）、`epNNN_clean.mp4`（无字幕母版）、`cover.png`及编辑源、九张原图、`voice.wav`、`mix.wav`、`episode.ass`、`episode.srt`、`subtitles.ruby.json`、`timeline.json`、`project.json`、素材/字体来源与检查报告。

## 6. 验收与交接

完整解码，核对规格、帧数/时长、混音削波、九图对应、无边缘黑线、封面短标题与安全区、每字拼音覆盖及实际烧录显示。完整听看发布版，复查字幕发音、句尾、镜头、留白、音乐与尾声；技术检查和人工听看分别记录，用户未验收则标待审。

交付时同步主控、台账和本集RECORD的版本、阶段、证据路径与下一候选。返工沿用集号、递增版本，复用未变的音频和图片；只改封面/字幕不重新请求配音。交付不等于发布。

## 阶段证据

| 阶段 | 通过依据 |
| --- | --- |
| 剧本 | JSON及阅读视图一致、采用版本已记录 |
| 配音 | 全句真实可解码，错读与句尾试听通过 |
| 图片 | 九张真实独立插画，逐镜对应剧情 |
| 封面 | 独立PNG与编辑源，短标题内容准确，模板与手机裁切检查通过 |
| 拼音 | 每字映射齐全，词语读音人工核对，字形与上下对齐通过 |
| 渲染 | 发布版、母版、字幕与时间轴实际生成 |
| 技术 | 完整解码及规格/字幕/削波检查通过 |
| 人工 | 完整听看意见、日期与审片者有记录 |
| 用户验收 | 用户对明确版本的反馈或确认原话 |

每项可标未开始、制作中、待审、通过、需修改或受阻。未运行的检查标未执行，不用计划或占位文件充当完成证据。
