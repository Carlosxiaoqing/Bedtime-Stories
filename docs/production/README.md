# 生产手册

入口：[制作主控](../../CHANNEL_MASTER.md) · [台账](EPISODE_STATUS.md) · [交接](../../HANDOFF.md)。

## 目标

逐集制作中文睡前绘本视频，延续已验收样片的温柔讲述、手绘水彩画面与缓慢剪辑。一次只制作用户指定的集数；剧本完成不代表图片、配音或成片已完成。

## 固定基准

- 语言：普通话中文；成片不穿插英语、词汇教学或跟读。
- 声音：使用 [声音规范](VOICE_PROFILE.md) 中的晓晓音色与已验收参数。
- 画面：9:16低饱和手绘水彩，暖灯与灰蓝夜色；角色按统一锚点保持连续。
- 剪辑：以语义和真实配音时长决定镜头，不为固定秒数截断句子。
- 实现：本地Python与FFmpeg合成、慢推拉和少量局部二维微动；不默认调用收费图生视频服务。
- 基准：第001集第二版，90.20秒、1080×1920、25fps、九个语义镜头、0.96秒叠化。

## 冲突处理

用户最新明确要求优先，其次是用户已验收成片和参数、本手册、单集剧本中的建议。历史版本只用于追溯，不覆盖当前规范。变更基准时记录谁确认、何时确认、改了什么以及新基准文件。

## 成品状态

每集分别记录：剧本、配音、图片、渲染、技术检查、人工听看。可用状态：未开始、制作中、待审、通过、需修改、受阻。只有实际生成并检查后才能标记完成；程序检查通过不等于人工完整听看通过。

## 标准生产顺序

1. 选定集数，读取该集结构化JSON、阅读视图和共用配置。
2. 校对口播、角色、地点与九镜画面对应关系；需要改稿时只改JSON并重新导出Markdown。
3. 按 [声音规范](VOICE_PROFILE.md) 合成逐句音频，试听后以真实时长排时间轴。
4. 按 [视频规范](VIDEO_SPEC.md) 生成九张真实独立插画，核对角色与画面，不用样片图代替新剧情。
5. 按[封面规范](COVER_SPEC.md)输出1张独立短标题封面；按[字幕规范](SUBTITLE_SPEC.md)逐字注音、人工校对并排版。
6. 混音、渲染无字幕母版及烧录拼音字幕的发布版，再运行技术检查。
7. 人工完整听看，记录缺陷、素材来源、实际参数、输出路径和验收状态。

## 交付

每集至少交付烧录逐字拼音字幕的发布MP4、无字幕母版、统一短标题封面PNG及编辑源、九张剧情原图、纯配音WAV、混音WAV、ASS、兼容SRT、字级拼音JSON、实际时间轴、项目参数、素材清单和检查报告。保留原始逐句录音、原图和提示词，确保后续可以局部返工。

- `03_素材与参数/`：声音、画风、角色、验收基准、素材索引和Windows Python 3.10离线wheel。

因此，文档与剧本可读，参数可核对；运行手册中的重建/生成命令需等04生产工程和所需媒体导入后再执行。
