# 三平台标题与正文交付规范

版本：1.0｜2026-11-10（北京时间）。用户指定从001重制起，每集完整交付视频、封面，以及抖音、小红书、微信视频号三份标题和正文，**每份正文中必须含标签**。

## 文件与内容

每集交付`发布文案.md`，按“抖音／小红书／微信视频号”分三个部分，每部分有独立标题与可直接复制的完整正文；#标签放在正文末尾，不只放在单独表格或附件。独立封面仅显示本集主题，不加账号或系列名；继续使用四字优先、必要时五或六字的短标题，平台标题可用完整故事名，不要求两者完全相同。

| 平台 | 默认写法（编辑目标，不是平台字数上限） |
| --- | --- |
| 抖音 | 简短标题，点明具体故事或画面；正文1–3句，简洁说明故事内容 |
| 小红书 | 短标题；正文可稍详细，用2–4个短段描述情境、亲子阅读场景及本集特色 |
| 微信视频号 | 标题直白温暖，突出故事名；正文自然连贯，适合家庭分享 |

每份正文默认3–5个相关#标签：睡前故事/儿童绘本、亲子共读、具体故事物件或亲子共读主题。根据内容选择，不堆热点，不使用无关标签；不以标签承诺平台流量。

## 与视频一致

描述当集真实故事，不剧透式编造新情节，不添加未呈现角色。拼音字幕可表述为“每个汉字上方配有拼音”，不宣传保证识字效果。避免“秒睡”“治愈失眠”等效果承诺；不加视频内口号、关注引导或教学跟读。

媒体制作前可以起草文案，明确标“初稿，待成片核对”；交付前核对视频、封面短标题、拼音字幕是否真实存在，删除不符描述。三平台各有一份正文并不代表已经发布；平台发布需另有授权，实际平台链接和时间单独登记。

## 检查清单

- 三个平台均有非空标题与正文。
- 每份正文末尾有相关#标签，可整段复制。
- 标题、正文、封面和最终剧情一致，描述的媒体特征已经实现。
- 发布前按平台当时界面的字数/话题规则调整；本规范不假设固定平台限制。
